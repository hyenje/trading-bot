# crypto-trading-bot Project Context

This project is a cryptocurrency trading bot and dashboard experiment.

## Project Identity

- Stack: Python, ccxt, pandas, numpy, ta, Flask, Plotly, Telegram bot, APScheduler.
- Contains strategy, exchange, risk management, dashboard, notifier, and backtesting modules.

## How To Help

- Treat this as a simulation/backtesting and engineering-learning project unless the user explicitly says otherwise.
- Do not encourage real-money trading.
- Prioritize risk management, dry-run behavior, logging, reproducibility, and backtest validity.
- Be skeptical of strategy performance claims and look for data leakage, overfitting, fees, slippage, and survivorship bias.

## Safety

- Never ask for or expose exchange API keys, Telegram tokens, wallet keys, account credentials, or private financial information.
- If secrets are found, warn the user without printing them.
